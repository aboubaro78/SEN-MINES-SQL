# 🇸🇳 SEN-MINES — Analyse du secteur minier sénégalais avec PostgreSQL

## 📌 Description

SEN-MINES est un mini-projet SQL réalisé avec PostgreSQL
pour analyser les activités minières au Sénégal.

L'objectif est de mettre en pratique les notions fondamentales
de SQL à travers une base de données relationnelle réaliste.

## 🎯 Objectifs

- Concevoir une base de données relationnelle
- Utiliser les clés primaires et étrangères
- Manipuler plusieurs tables avec JOIN
- Effectuer des agrégations
- Analyser la production minière
- Répondre à des questions business avec SQL

## 🗄️ Modèle de données

La base contient 5 tables :

- regions
- entreprises_minieres
- sites_miniers
- substances
- productions_minieres

## 🛠️ Technologies

- PostgreSQL
- SQL
- pgAdmin / VS Code

## 📊 Analyses réalisées

Le projet répond notamment aux questions suivantes :

1. Quelle est la production totale par substance ?
2. Quelles sont les 5 substances les plus produites ?
3. Quelle est la production totale par année ?
4. Quelle entreprise produit le plus ?
5. Quelle région possède le plus grand volume de production ?
6. Quelles entreprises dépassent 1 million de tonnes ?
7. Quels sites produisent de l'or ?
8. Quelle est la plus grande production enregistrée ?
9. Combien de sites possède chaque entreprise ?
10. Quelles années dépassent 5 millions de tonnes ?

## 📚 Source et données

Les noms de plusieurs entreprises et substances sont inspirés
de données publiques de l'ITIE Sénégal et du Ministère de l'Énergie,
du Pétrole et des Mines.

Les données de production utilisées dans ce projet sont
des données pédagogiques simulées destinées à l'apprentissage de SQL.
